# STRYKEFOX MEDICAL

Healthcare infrastructure, engineered for what comes next.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `src/app/page.tsx` - Main homepage with all four sections
- `src/app/layout.tsx` - Root layout with global styles
- `src/app/globals.css` - Tailwind CSS and custom styles
- `public/images/` - Placeholder images for the design

## Sections

The homepage includes four main sections:

1. **CarePath** - Care that follows the patient
2. **Northstar Surgical Innovations** - Innovation built around the operating room  
3. **SPEAR** - Deployment intelligence behind the platform
4. **SoC13** - Expansion by design

## Technologies Used

- Next.js 14
- React 18
- Tailwind CSS
- Lucide React Icons
- TypeScript
